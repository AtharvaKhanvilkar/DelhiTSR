AutoTSR — Document Reconciliation Platform for MH Property

Project Creation

  • Users create a new project by specifying a project name and the key property identifier type (Survey Number, CTS Number, or Plot Number).
  • They then enter the actual identifier value, which helps label and organize the project for quick reference.
  • DDR Engine generates a unique workspace for each project, keeping all uploaded documents organized.

Workspace & Document Upload

  • Each project has its own workspace.
  • Users can upload property documents (PDFs) directly into the workspace.
  • The platform maintains a sidebar showing all uploaded documents for easy access.
  • The sidebar also prominently displays the project name along with the entered Survey/CTS/Plot number, providing immediate context for every workspace.

Automated Data Extraction

  • Once a document is uploaded, AutoTSR leverages Google’s Gemini AI to extract structured information based on a strict, pre-defined schema.
  • This includes essential fields like registration number, document type, license fees, licensor and licensee details, and plot or survey information.
  • The AI ensures high accuracy and consistency, converting unstructured PDFs into a machine-readable JSON format.
